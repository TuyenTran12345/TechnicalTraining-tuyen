Workflow overview in one table
Solution
BPMN 2.0 workflow engine for visual design, automated execution, and real-time monitoring in Odoo.
Problems solved
Manual tracking, rigid automation rules, low process visibility, scattered logic, and inconsistent execution.
Design
Drag-and-drop BPMN editor with tasks, gateways, events, pools, lanes, XML editing, and workflow versioning.
Triggers
Manual launch, event-based start on record changes, and recurring schedules by day, week, month, or year.
Execution
State-driven engine with automatic tasks, manual assignments, waiting events, error handling, and priority scheduling.
Integration
Attach to any Odoo model, run server actions, assign users dynamically, use activities, and push live status updates.
Advanced control
Concurrent instances, conditional routing with domains, subprocesses, input/output mappings, retry, and skip with approval.
Monitoring
Execution history, visual state viewer, stack-trace errors, progress tracking, log retention, and automated cleanup.
Security
Role-based, model-based, and record-level access control with organized task assignment by pools and lanes.
